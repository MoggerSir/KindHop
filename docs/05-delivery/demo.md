# Demo para jueces (2–3 minutos)

1. **Problema:** las ciudades tienen información dispersa; NEXO fue nombre preliminar, ahora el producto se llama **KindHop**.
2. **Cancún:** abrir mapa con puntos y una ruta de transporte respaldada por fuente, seleccionar destino.
3. **Contexto urbano:** mostrar una incidencia simulada **con etiqueta DEMO** y una alternativa explicada. No alegar riesgo o seguridad comprobados.
4. **Economía:** registrar gasto de transporte y observar actualización de presupuesto.
5. **Multiciudad:** cambiar a CDMX, ver mapa y una integración diferente sin recargar la arquitectura.
6. **Cierre:** explicar motor de adaptación, fuentes, escalabilidad, métricas posibles y limitaciones honestas.

**Plan de respaldo:** video pregrabado de la misma app funcional; dataset local autorizado y etiquetado si una API falla; no suplantar datos reales con falsos sin marcar.
