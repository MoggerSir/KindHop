# Checklist de lanzamiento y verificación

- [ ] `npm install`, `npm run check`, `npm run build` ejecutados y resultados registrados.
- [ ] Web mobile, tablet y desktop sin overflow; `prefers-reduced-motion` respetado.
- [ ] API health responde y no revela secretos.
- [ ] Mapa con atribución; fuentes y licencias comprobadas.
- [ ] Cancún y CDMX cambian su configuración/capas.
- [ ] Rutas/POI con origen y fecha; sin datos falsamente en vivo.
- [ ] Incidencias en demo marcadas; caducidad y estados.
- [ ] Budget integer cents y sin datos de tarjetas.
- [ ] Al menos un flujo E2E completo y repetible.
- [ ] README/FILEMAP/contrato actualizados tras cambios.
- [ ] `git status` limpio y commits nuevos hechos hoy.
- [ ] Pitch de 2–3 min ensayado con demo alternativa.
