# Módulo: explorar + eventos

**POI:** establecimientos, playas, plazas, parques y museos desde OSM, gobiernos o fuentes propias con licencia. Mostrar categoría, título, coordenadas, fuente y enlace oficial cuando exista. No scraper masivo de Google Maps.

**Eventos:** cartelera por ciudad con `name`, `startAt`, `endAt`, `venue`, `link`, `source`, `verifiedAt`, `status`. Eventos pasados no deben mostrarse como próximos. Filtros por fecha/tipo.

**MVP:** lista de eventos de ejemplo reales con referencias verificables y fecha; si no hay información vigente, estado vacío honesto. Añadir eventos a un recorrido es P1/P2.
